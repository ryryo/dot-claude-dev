# 計画・起動・受渡しの雛形

案件固有値だけを実在参照で埋める。空欄の一般雛形は認可の証拠ではない。既存記録があれば参照と差分だけを使い、規則全文・全起動文・日次コピーを繰り返さない。

## 計画

```text
原依頼/実行許可: <実際の利用者指示・承認済み計画>
到達点: <phase、全原scope、元body/check/必要levelへの参照>
分母: <全ID集合、初回/後続/承認移管の根拠、未割当/重複/未確認>
正本: <唯一の正本、CLI、更新手順、現在revision>
体制: <実行指揮者、必要なら対話専任、領域PMの責務>
順序/能力: <供給者、固定成果/consumer受入、通常接続、解除条件>
共有境界: <編集/統合/検収窓口、project環境手順>
実行設定/認可: <役割別モデル・推論、方式/開始元、委任・通信・commit>
継続方式: <実clientと許可済み方式、未確認・再開できない条件>
外部実行が必要な場合: <projectの実行条件への参照と不足>
実行モード: <通常/統合集約、根拠、切替/終了条件>
```

## 実行オーケストラ

```text
役割: 全原scopeの継続開発を指揮する実行オーケストラ
計画/原依頼/開始承諾: <参照先と対象版>
全scope/担当/順序/共有責任: <初回・後続・承認移管を含む参照>
正本/CLI/現在revision: <確認済み情報>
現成果/採用/未回収: <固定版と既存handoffへの参照>
モード/統合先/開始基点: <通常または統合集約。M未確定なら未確定>
対話役: <ある場合の正式ID、読取経路、通信許可>
実行条件/委任/通信/commit: <既存許可と設定。未承認部分も区別>
継続方式: <確認済み参照と不足>
実行入口: <gantt-development-orchestrator/SKILL.mdの確認済み絶対パス>
```

## 対話専任

```text
役割: 利用者との要求・方針・判断整理を担う対話専任
原依頼/判断資料: <実在参照と対象版>
直接読取: <正本、code/diff、実thread、採用版、証拠への許可済み経路>
実行役: <正式ID/host、実際に許可された通信範囲>
編集範囲: <必要なら私有判断資料のみ。製品・task status変更は対象外>
未確認の読取/再開能力: <取得時点・snapshot制限等>
入口: <大規模SKILL.mdの確認済み絶対パス>
```

## 領域PM

```text
役割: <区分>のプレイングマネージャー
全scope: <初回・後続・承認移管を含む全原IDと責務根拠>
完了条件: <元body/check/必要level、区分全体の到達点>
順序/必要能力: <承認済み順序、供給/利用関係、解除条件>
既成果/採用版/保留: <固定Source、consumer/main版、未回収への参照>
編集/共有境界: <中核、専有範囲、通常入口、供給先、検収窓口>
正本/CLI: <確認済み絶対パス・更新手順>
実行モード: <通常/統合集約>
設定/環境: <既認可モデル・推論・方式/開始元、project setup>
実行役/通信: <正式ID・host・実際の許可>
worker/commit/外部実行: <既承認範囲とprojectの実行条件への参照>
継続方式: <現clientで確認した再開手段・未確認>
最初に読む契約: <playing-manager.mdの確認済み絶対パス>
```

全体役は個々のworker成果をここで全て決めない。PMが担当内で切り出し、workerへの依頼は共通の[task-contract](../../codex-task-split/references/task-contract.md)を使用する。

## 部分供給と次ID

```text
対象: <元ID/check> / 現工程: <実装・接続・検収・正式化等>
成果: <固定Source、owned、前提、実検証と必要level>
採用: <consumer版/main版/未受入>
利用側: <担当・元ID・通常呼出元、解除する能力>
残条件: <元checkの不足、失敗/未実施>
次: <同ID/次ID・実装する条件・開始能力/阻害理由>
```

## 統合集約への切替とhandoff

```text
切替根拠/対象: <実利用者指示と対象scope/checkout>
区切る成果: <現在の最小成果と既存worker。新ID/worker/WTへ広げない>
固定版: <HEAD/base、owned、index/WIP/untrackedの識別と所在>
検収: <成功/失敗/未実施、原checkの充足と残件>
worker/process: <正式thread/依頼回/編集・書込停止状態>
state保護: <privateな所在/所有/復元手順への参照。秘密の内容は含めない>
全差分処遇: <採用/既採用・代替/重複/保留の行先と理由への参照>
受領/移管: <回収責任者、未受領、新owner未確定等>
再開条件: <検収main M、全scope移管、同M開始確認、通常へ復帰>
```
