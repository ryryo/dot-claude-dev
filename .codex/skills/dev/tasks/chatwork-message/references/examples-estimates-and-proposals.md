# 概算・見積もり・範囲の相談・提案の実例

対応可否、概算、費用の前提、発注や追加作業の範囲を相談する例。金額・条件・納期は文体の参考用の置換であり、新しい依頼へ転用しない。

[使い方と文体の傾向](writing-style.md) / [全パターンの索引](examples-index.md)

本人アカウントの過去投稿を元にした匿名化例。案件固有の情報を置換し、返信先・引用元の表示を除いています。「抜粋」は1投稿の一部で、別投稿をつないだ文例は含みません。原文の表記揺れや一部の誤記は残っています。

## E02 実装方法ごとに金額を分ける

```text
方法Aか方法Bかで手間が変わりそうで、お見積もりは、
・方法Aの場合：［概算金額A］
・方法Bの場合(別ページをスキップしている店舗)：［概算金額B］
となります。

クライアントに打診すると共に、先にどの店舗様のものかも予め共有いただけますと助かります!
```

## E06 見積もりが概算になる理由を説明し、発注まで待つ

種別：匿名化した本文。

```text
残っていたタスクの見積もり情報を追加しています。
ちょっと以前のもので、タスクの大きさが詳細に確認できていないため、ざっと概算程度にはなります。

内容も改めて確認です。

- 既存ページの設定変更
対象のページ内で、電話番号など変数で指定した方が、今後コピーした際にも扱いやすい部分が、現状直接コピペ入力なってしまっている部分が多く、それ改修するといった内容だったかと思います。
作業の難易度は大したことないのですが、件数がどれくらいあるか、現状まだ確認できていないためそこで金額が変わってきそうです。

- ［対象案件］のフォームポップアップ修正
特にiOSでポップアップのフォームの入力時に、カーソル位置がずれるなどの問題があった点の改修です。
iOS実機で都度確認しながら直していくため、あっさり直るかが分かりづらく、とはいえ大きくなっても［上限の目安］は超えないかなという概算になります。


こちらご確認ください! 発注となるまで、すべて待ちとしておきます。
```

<a id="e08"></a>

## E08 流用で済まない理由と、予算に合わせる余地を伝える

種別：匿名化した抜粋。

```text
参照元が旧構成のものだったため、単純なコピーでは済まなそうという初見でいます。

- 現在の構成の上に、参照元のような形式を作る ［概算範囲］
が詳細見る前のざっとした概算になります。

項目としてはシンプルなはずなので、思ったより簡単に終わったみたいな可能性もありつつ、
現在の構成は基本のファイルが共通化されているので他に影響でないように、考慮しながらとなると参照元をコピーして［低い方の予算］で済むってことは無さそうかなという感触でいます。

今後のこと考えてしっかり汎用的に使えるようにしておくのか、今回だけの例外としてある程度ゆるく作るか、という話でもあるので、この予算の範疇でというご指定の中でもできるかなと思います!
```

## E09 再利用と個別対応のバランスを相談する

種別：匿名化した抜粋。

```text
そうですね!今後のことを考えて、既存機能の派生として使い回しできるように作る形になります。

今の形だと、店舗様ごとのカスタマイズもそれなりに柔軟にできますが、システム化の際にはどこまでそれを許容するかも考慮していかないとですね。
```

## E10 大きな見積もりを必要な範囲へ絞る相談

種別：匿名化した本文。

```text
先日いただいたコメントを反映し、見積もりに関しても概算ですが、ざっとまとめたものをお送りいたしますので、ご確認お願いします!

要件定義費とデモ制作費に関しては、取り急ぎの一番MAXな額をとりあえず書いています。ここから実際必要な範囲に減らすようなお話ができたらいいのかなと思っています。システム屋さんだとこれぐらいで出しそうってものですね。

要件定義に関しては、今回、結局私一人での開発になりますし、そんな綺麗に整える必要があるものでもないと思うので、申請にあたり必要最低限のものがあれば良いのかなとは思っています。
実際どの程度、資料として必要なのかという部分を調整し合わせられればですが、別途下書きを添付するのでこれぐらいの粒度のもので良さそうかご確認いただければです。

デモページ制作に関しては実際にそれをベースとして制作していくことにもなると思うので、デモとして必要がないページは削りつつも、主要な部分はデモとはいえしっかり作り込むぐらいの温度感で良いのかなとは考えています。
```

## E13 提案範囲を追加した理由と、別見積もりの境界を伝える

種別：匿名化した抜粋。

```text
打ち合わせ時からの大きな変更点として、当初は第2弾以降を想定していた基本的な編集機能を、今回の提案範疇に追加しています。

元々の素材の組み込み時点でそうだったのですが、［担当者］さんからも追加の要件としてあった表示内容の追加、素材の追加など考えると、やはりエディタは必要かと判断したためです。

本来今回のご予算ですと、そこまで収まりきらないのですが、弊社でも今後の制作事業などを見据えると、自社用としてもエディタ開発は必須という面もあり、提案に含めさせていただきました。

なお、今後エディタに［相手の会社］専用の機能追加や、他のシステムとの連携、詳細な権限設定などが必要になった場合は、別途お見積りとなります。

ご確認いただき、気になる点や修正したい箇所がございましたらお知らせください!
```
