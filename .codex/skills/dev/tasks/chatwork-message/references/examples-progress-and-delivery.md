# 途中報告・説明・完了報告・引き渡しの実例

作業の到達点や確認した範囲を具体的に伝える例。完了・テスト済み・共有済みなどの実施内容は、現在の事実がある場合にだけ使う。

[使い方と文体の傾向](writing-style.md) / [全パターンの索引](examples-index.md)

本人アカウントの過去投稿を元にした匿名化例。案件固有の情報を置換し、返信先・引用元の表示を除いています。「抜粋」は1投稿の一部で、別投稿をつないだ文例は含みません。原文の表記揺れや一部の誤記は残っています。

<a id="p01"></a>

## P01 最低限どこまで確認したかを先に知らせる

種別：匿名化した本文。

```text
細部の確認を何もできていないのですが、とりあえず基本のファイル設置と一応フォームが最後まで遷移することと、GASの書き込みがされる部分までだけ確認済みです。
また後ほど調整していければですが、取り急ぎのご報告まで。
```

## P10 現在の修正範囲と、その後の移行予定を伝える

種別：匿名化した本文。

```text
［対象案件］は、対象の設定ファイルの修正と、対象のスクリプトの変更で戻るボタンを押した際に切り替わらない問題を修正しただけの状態です。 「対象バージョン」こちらは問題なく動作するかと思います。
```

## P11 今後相手が自分で更新できる条件を説明する

## P15 接続完了と、実際に確認した範囲を伝える

種別：匿名化した本文。

```text
デモ用2本のmaster・GASの設置と接続設定、完了しました!
下記に設置済みです。

■サンプルA
- ［参照URL］

■サンプルB
- ［参照URL］

2本とも、［共有先メールアドレス］ に編集権限で共有設定入っています。defaults.phpへのURL設定までこちらで済ませています。

実際のフォームからテスト送信し、masterへの記録、ご指定の既存顧客リストのdata_importへの転記、管理者・顧客向けメールの受信まで確認済みです。

また一部フォーム側の設定漏れもあったので、そちらの調整も行いました。
```

## P16 複数案件の状態・費用・順序を一度に共有する

種別：匿名化した本文。

```text
お待たせしております！
諸々内容詳細の確認やドキュメントを整えてからご連絡したかったのですが、［遅れの事情］があり、先に要点だけ共有させてください。

① 不要フォームの削除
削除対象を参照していたパスなどは修正し、削除できるよう整理済みです。バックアップを取っていただいたうえで、対象確認済みのものはそのまま削除いただいて大丈夫です。バックアップ後、こちらで代わりに削除する形でも対応できます。

② デモ用の設定
master・GASの作成と転記設定で、まとめて［概算金額］（税込）でいかがでしょうか。接続後の軽微な調整も含め、できれば明日中に対応してURLをお渡ししたいと考えています。

③ 既存案件の移行
ひとまず［概算金額］（税込）で進められる想定です。細かな仕様の違いは基本的に現在の構成の標準に揃え、個別の実装で大きく工数が増えるものが見つかった場合のみ、事前にご相談させてください。

④ 作業順序
現在の修正対応に続き、デモ用の設定 → 新規立ち上げ（ご指定の納期）→ 既存案件の移行、の順で進める想定です。

取り急ぎのご連絡となりますが、よろしくお願いいたします！
```
