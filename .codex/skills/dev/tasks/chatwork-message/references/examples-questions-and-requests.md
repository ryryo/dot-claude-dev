# 確認・依頼・情報不足・認識合わせの実例

相手の説明から自分の理解を示し、判断に必要な点を具体的に聞く例。「こちら」「そちら」は元の文脈に依存するため、新しい文面では対象が伝わるかを確認する。

[使い方と文体の傾向](writing-style.md) / [全パターンの索引](examples-index.md)

本人アカウントの過去投稿を元にした匿名化例。案件固有の情報を置換し、返信先・引用元の表示を除いています。「抜粋」は1投稿の一部で、別投稿をつないだ文例は含みません。原文の表記揺れや一部の誤記は残っています。

<a id="q01"></a>

## Q01 アクセスできるか確認する

種別：匿名化した本文。

```text
了解しました🙇‍♂️ また情報が別の場所に移行とのことで、こちら権限いただけてそうでしょうか?
［添付画像］
```

## Q09 想定と別の可能性を並べて確認する

種別：匿名化した抜粋。

```text
とのことですが、 ［参照URL］ の中に、シンプルに登録フォームを埋め込むということで良さそうでしょうか?

対象店舗の情報だけが［資料サービス］上にあるので、そちらのフォームだけを設置すれば良いのかと想定しつつ、LP上には姉妹店様へのリンクもあったので、既存のもののように複数店舗対応にする可能性も見受けられたので念のためご確認まで!
```
