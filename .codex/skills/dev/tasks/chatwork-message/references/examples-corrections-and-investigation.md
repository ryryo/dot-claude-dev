# お詫び・訂正・調査・未確認事項の実例

失念・連絡遅れ・取り違え・調査中の状況を伝える例。ミスがある場面の文体であり、通常のお礼や進捗連絡に謝罪や不具合の話を足すための例ではない。

[使い方と文体の傾向](writing-style.md) / [全パターンの索引](examples-index.md)

本人アカウントの過去投稿を元にした匿名化例。案件固有の情報を置換し、返信先・引用元の表示を除いています。「抜粋」は1投稿の一部で、別投稿をつないだ文例は含みません。原文の表記揺れや一部の誤記は残っています。

<a id="c01"></a>

## C01 失念を認めて、直近の作業予定を伝える

種別：匿名化した本文。

```text
すいませんこのこちら失念しておりました🙇‍♂️ 今日明日でベースの構築進められればです
```

<a id="c02"></a>

## C02 時間が限られており、できるか言い切れない

種別：匿名化した本文。

```text
申し訳ないです🙏 　側だけでも進めてみますが、打ち合わせにももう少しで入ってしまうので最低限見せれるものにできるか半々なところです!
```

<a id="c03"></a>

## C03 ミスを詫び、再発を避ける作業を伝える

種別：匿名化した抜粋。

```text
こちら大変失礼いたしました🙇今後注意しつつ、今回のものも上書きしないようデータDL済みです。
```

<a id="c04"></a>

## C04 取り違えを認め、必要な情報と調査結果を伝える

種別：匿名化した本文。

```text
話の流れで［対象案件］のものと誤解しておりました失礼しました! このような際はスプレッドシートのURLをいただけると助かります🙏
［参照URL］

特にコードの変更などはなく、間が空いてしまう行を全て削除してからテストしたら、正しく追加されたのですがこちらで問題なさそうでしょうか?
空の列に見えていたけど、どこか一箇所だけスペースなど入力が実は入っていて入力済み判定になってしまっていたのかなと思います。
```

<a id="c05"></a>

## C05 返信遅れを詫びて対応を返す

種別：匿名化した本文。

```text
返信失礼いたしました。対応します!
```

<a id="c06"></a>

## C06 推定原因と修正、経過確認の依頼を伝える

種別：匿名化した抜粋。

```text
こちらの件、新機能の影響でなく、本番環境で既存機能の設定に切り替えができていなかった部分が原因の可能性が高そうでした。
その点の修正を入れたので、お手数ですが、また引き続き様子の方を見ていただければです。よろしくお願いいたします。
```

<a id="c07"></a>

## C07 一連の対応は済んだが、見直しが残っている

種別：匿名化した抜粋。

```text
見直しがまだ仕切れていない状態なのですが、取り急ぎ一連できた状態なのでご確認をお願いできればです!

対象のフォームに関して元々、入力項目が完全に固定して作られていた部分があり、同じ構成のフォーム全体の共通ファイルにも変更を入れています。
問題が出ない範疇の変更だとは思うのですが、同じ構成のフォーム全体でなにか問題が出る可能性もあるため、その際は別途ご連絡いただると助かります。
```
