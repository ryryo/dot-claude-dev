# Devinへの依頼と修正の雛形

必要な部分だけを使い、括弧を現行の実情報へ置き換える。調査だけなら実装・PRの工程を除く。過去のtoolchain版・repo・モデルを固定値として再利用しない。

## 作業をPRにする

```text
（owner/repository）の（base、確認commit）から、次の一まとまりの作業を実装し、commit・専用branchへのpush・PR実登録まで進めてください。
目的・期待する動作：（内容）
既知の問題・根拠：（症状、パス、確認した版。未確認は未確認と記す）
所有する編集範囲：（ファイル／モジュール）
維持する契約：（公開仕様、既存動作、保存・実行境界）
対象外：（今回触らない範囲）
受入条件・必要な検証：（観測できる結果）
同じ作業の既存PR・担当：（URL／なし、衝突条件）

実取得したAGENTS.md・README・セットアップ・必要な設計と呼出元を読んでください。
参照repo：（owner/repository、ref、役割、内容調査を許可する範囲）
共有スキルが必要なら：（実体repo、ref、パス、隣接配置・Git管理外リンクの方式）
実際に読めたcommit・契約と、Git管理外リンクのresolveを確認してください。
ローカルだけにある未反映成果：（なし／内容と避ける編集対象）。remote反映済みと扱わないでください。
役割・モデル：（適用契約と許可済み例外）。表示で確認できない設定へ適合したと主張しないでください。

環境は（指定toolchain）を公式配布・既存管理ツールで準備し、既存の隔離ランナーと固定lockfileを使ってください。
VMに合わせて製品版・lockfileを変更したり、制作state・資格情報を持ち込んだりしないでください。
OS・GUI検収が必要なら、対象OSは（OS・必要版）、対象ブラウザ／アプリは（名前・版）です。
Computer Useで（実操作と期待結果）を確認し、必要なら短い録画を返してください。
実IME／WSL2等が条件なら実際の利用可否を確認し、イベント注入や別OSの成功で代用しないでください。
実OS・toolchain・検証commit、操作条件・保存前後・成功／失敗・未確認を示してください。
適用契約に従ってclean・最新remoteを確認し、他者の成果を保持して専用branch（codex/作業名）を使用してください。
同じ作業のbranch・PRがあれば継続し、重複作成や他人のbranch上書きをしないでください。

今回の許可は調査・準備・指定範囲の実装・必要な検証・commit/push・PR作成までです。
通常の局所失敗は範囲内で修正して続け、未決仕様・範囲外の変更・新しい権限等が必要なら根拠と影響を示してください。
baseへの直接push、自己マージ、deploy、再委譲、別台帳への進捗更新は行わないでください。
GitHubの書込権限は本来の成果branchとPRで確認し、ダミーPR・新規token・権限拡大は行いません。
公開差分・PR本文・自動footerには、非公開会話URL、内部資料、旧repo参照、個人パスや秘密情報を含めないでください。

PR本文は問題と修正結果、維持契約、検証・未実施を短く説明してください。
結果にはPR URL、base/head、変更ファイル、pushとPR登録の個別確認、実toolchain版、検証結果・未実施・残件を示してください。
有用な環境提案があれば対象repoとスクリプトを提示し、保存・build・Activeの現状態を報告してください。採用はCodexが確認して行います。
```

## レビュー指摘を修正する

```text
同じ作業の（PR URL、確認head）をレビューしました。
問題：（具体的な動作／記述と箇所）
根拠：（対象版のコード、契約、検証結果）
期待する結果：（受入条件）
修正範囲：（既存の所有範囲と必要な変更）
再確認：（変更に影響する検証だけ）
確定事項：（保持する仕様・既存の合意）

同じbranch・PRを修正し、必要な検証を行って更新してください。
他者変更・公開情報境界を保ち、mergeはしないでください。更新head、差分、検証結果、未実施を返してください。
```

## 環境提案・状態報告を訂正する

```text
提案（対象repo、snapshot等）を確認しました。
修正すべき内容：（スクリプト／版／state境界等と根拠）
設定画面で確認した現状態：（保存、build、成功、Active等）
必要な工程だけを修正・実行し、製品コードで環境問題を回避しないでください。
既に完了した保存・build・有効化や、別repoの設定変更を追加しないでください。
現状態と証拠、未完の工程を報告してください。
```
