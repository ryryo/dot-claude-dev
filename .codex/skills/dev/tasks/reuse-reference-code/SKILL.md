# 先行実装を直接読んで再利用する

先行実装の良い処理を活かして、依頼された機能を実装する。調査資料や設計メモは元コードを探す入口として使い、実装時には元コード自体へ戻る。

## 進め方

1. **書く直前に元コードを読む。** 参考にするファイルを手元で読める状態にし、対象の関数・クラス・コンポーネントの全文を改めて読む。長ければ分けて読む。以前の調査要約、検索で得た断片、記憶だけでコードを書き始めない。処理を理解するために必要な呼び出し元・関連処理・テストも読む。元コードを取得できなければ、読めたことにして再現実装へ進まず、不足を伝える。
2. **使える処理は再利用する。** そのまま使える部分は複製し、移植先への接続に必要な箇所を改変する。優れた処理を、短くできる・自分で書けるという理由だけで書き直さない。
3. **構成が違っても元コードを見ながら組み込む。** そのまま複製できなければ、必要な処理を取り出すか、移植先の構成に合わせる。元に不具合がある場合や、書き直すことで機能・保守性が良くなる場合は書き直してよい。その場合も元の実装を直接参照し、必要な動作を引き継ぐ。
4. **元の動作と照らして確認する。** 対象の分岐・境界条件・例外処理・後始末を落としていないか、元コードやテストと比べる。元テストを使える場合は再利用し、移植先への接続も確認する。

調査だけの依頼では実装を始めない。後で採用して実装へ進むときに、この手順を使う。
