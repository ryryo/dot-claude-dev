# 大規模契約の参照先

大規模モードの[起動手順と送信本文](../../gantt-development-orchestrator/references/task-launch.md)を直接使ってください。[点検タイマー](../../gantt-development-orchestrator/references/execution-review.md#カテゴリの定期点検タイマー)と[移管時のhandoff](../../gantt-development-orchestrator/references/consolidation.md#2-handoffで保持するもの)は、それぞれ必要な場合だけ読みます。

既存の複数ID担当を移す場合は、scopeを縮めず、承認された[所有移管](../../gantt-development-orchestrator/references/consolidation.md#1-単体id担当への所有移管)でWIP・claim・証拠・未回収を引き継ぎます。この案内は新規起動・通信・移管・再開の許可ではありません。
