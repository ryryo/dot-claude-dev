# 通常側の少数回帰ケース

スキル改訂時の判断・動作確認用。通常taskの必須Gateや常設監視ではない。実モデル試行・実client試行は実行した場合だけ記録し、本文の単語一致で合格にしない。

| 入力 | 合格する動作 |
| --- | --- |
| ガントの提案だけ依頼 | 限定候補・分担・順序で終了。create/claim/課金をしない。大規模資料を読み込まない。 |
| 対象IDに旧担当と未回収差分 | 実threadと現物を確認し、回収/移管を優先。新規担当を重ねない。 |
| 既承諾のLuna/max・Worktree | 実schemaと宛先を確認して同じ設定を使う。別方式へ代替しない。 |
| 小さな単独修正 | 担当が直接実装・検収。不必要なworker・追加承認を作らない。 |
| worker completed、通知なし、未commit | 親が待機前/再開時に回収。親が正式化し、通知待ちで放置しない。 |
| 部品試験成功、通常接続失敗 | 元checkは残し、失敗条件を調べる。テスト件数でdoneを作らない。 |
| 設定上の依存拒否 | 是正先と根拠を特定し、独立作業を続ける。依存削除・詳細化迂回をしない。 |
| 限定依頼の完了 | 残件・正本・採用版を確かめて終了。新領域、Goal、監視、archiveへ広げない。 |

結果には入力版・モデル/設定・実行した動作・採用/未完の根拠・未確認を残す。実装の品質と起動/配送の成功を別々に判定する。
