# 大規模契約の参照先

現在の正本は[回帰確認ケース](../../gantt-development-orchestrator/references/review-cases.md)です。大規模モードはカテゴリ別オーケストラ → 元ID一つごとの新規chatのPM → 限定実装workerで進めます。

既存の複数ID担当は、scopeを一つへ縮めず、承認された[所有移管](../../gantt-development-orchestrator/references/consolidation.md#1-単体id担当への所有移管)でWIP・claim・証拠・未回収を引き継ぎます。この案内の読取りは新規起動・通信・移管・再開の許可ではありません。既存の許可・停止指示・未移管の責任を保持してください。
