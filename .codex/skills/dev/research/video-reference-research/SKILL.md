# Video Reference Research

動画を後から調べ直せる根拠付き資料へまとめる。字幕を手掛かりに映像を確認し、説明された内容、観察できた事実、分析を区別する。

## 入力と保存先

動画URLまたは保存済み動画、資料の用途、必要なら対象範囲・保存先・言語を受け取る。既存の依頼から分かるものは再質問しない。用途によって調査範囲が大きく変わり、判断材料がなければ用途だけを確認する。

- 指定動画を対象とする。追加検索は依頼または不足する根拠に応じて行い、追加理由を記録する。
- 日本語資料を既定とする。原文の固有名詞や引用と、日本語による説明・翻訳を区別する。
- 保存先は利用者指定を優先する。未指定時は作業ディレクトリ内の`research/video-references/{YYYY-MM-DD}_{slug}/`とする。
- 既存の字幕・メタデータ・キャプチャを確認し、同じ動画・言語・範囲の利用可能な資料を再利用する。

## 進め方

### 1. 出典と字幕を揃える

YouTubeでは[既存のyoutube-transcript-research](../youtube-transcript-research/SKILL.md)を読み、その取得スクリプトを使う。URL指定時は検索を省略できる。本スキルが字幕から最終資料までの整理を担うため、同じ要約を別途作り直す必要はない。

既存スクリプトの`fetch`は字幕とメタデータの取得であり、動画本体はダウンロードしない。スクリプトのパスはリンク先スキルのディレクトリを基準に解決する。資料の保存先配下へ字幕の出力先を指定し、対象動画の言語に合うトラックを選ぶ。

YouTube以外では提供字幕や利用可能な字幕取得手段を使う。字幕がない場合、既存スキルの音声認識条件と実行環境に従う。文字起こしができなくても映像から確認できる範囲は資料化し、字幕未取得・音声未確認と対象範囲を明記する。

動画ごとに出典ID、URL、タイトル、発信者・話者、公開日、長さ、調査日、字幕の言語と取得状態を記録する。不明な項目は推測で補わない。

### 2. 論点と映像の確認箇所を決める

字幕全体を読み、テーマ、主張、説明、実例、図表、質疑などを時刻と対応付ける。長い字幕は分割して読み、読了範囲を管理する。キーワードの一致箇所だけで全体を把握済みにしない。

- 講義・解説は、概念とその説明、図表、実演の関係を整理する。
- 対談は、話者ごとの主張、合意・相違、質問と回答の文脈を保つ。話者を特定できなければ断定しない。
- 製品UI・操作が目的なら[製品UIの調査](references/product-ui.md)を読み、機能と一連の操作を棚卸しする。

### 3. 映像を確認して証拠を選ぶ

[映像確認とキャプチャ](references/video-evidence.md)を読む。ブラウザー等で元動画の該当時刻を直接参照する方法を優先し、確認や切り出しに不足する場合のみ一時取得を使う。

字幕時刻を映像の確定時刻にしない。発話と画面がずれる場合は前後を確認する。動きの主張には連続区間を確認し、見た目を説明する箇所には読み取れる根拠画像を添える。図や画面に意味がない対談へ、装飾目的のキャプチャを増やさない。

### 4. 資料を組み立てる

入口の`index.md`に目的、確認範囲、対象動画、要点、テーマ別本文、出典、未確認点をまとめる。詳細カタログは量に応じて分離し、入口から辿れるようにする。

| 根拠の区分 | 記録する内容 |
| --- | --- |
| 映像で確認 | 見た画面、図表、操作と到達状態。説明の真偽まで保証しない |
| 字幕で説明 | 発信者の説明・主張と該当時刻。字幕の誤認識、翻訳、音声未照合を必要に応じて記す |
| 分析・提案 | 根拠から導いた解釈や適用案。出典の発言や利用者の採用決定と混ぜない |
| 未確認 | 確定できなかった点、理由、確認すべき時刻・操作・資料 |

各論点・観察から時刻付きの動画リンクへ戻れるようにする。根拠画像は説明箇所へ埋め込み、何が確認できるかと確認の限界を添える。引用は必要な短い範囲に絞り、直接引用と翻訳・要約を区別する。

複数動画で主張・UI・挙動が異なる場合は、出典と公開日を並べて差分を残す。動画公開時点の観察を現行仕様へ読み替えない。主張の事実検証まで求められた場合は別の一次情報を照合し、動画由来の根拠と区別する。

## 完了条件

- 指定範囲の内容を棚卸しし、確認済み・未確認の範囲が分かる。
- 要点、本文、画像の観察内容が対応し、元動画の該当時刻へ戻れる。
- 採用画像は目視済みで、字幕だけの説明や推論を映像確認済みにしていない。
- 相対リンク、画像参照、出典ID、キャプチャmanifestの対応を確認した。
- 字幕未取得、映像取得不能、低解像度などの制限が資料に残っている。

実機操作、採用範囲の決定、Story更新、デザイン・実装は別工程とする。依頼が資料化までなら、調査成果と未確認点を渡して完了する。元動画を通常の納品物へ含めず、既存の利用者ファイルを削除しない。
