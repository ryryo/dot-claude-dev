# 映像確認とキャプチャ

字幕から選んだ時刻の映像を確認し、資料に残す画像を採用するときに読む。

## 直接参照を優先する

1. 実行環境で利用可能なブラウザー・動画閲覧手段の手順を確認し、元動画URLを開く。YouTubeでは`https://www.youtube.com/watch?v=VIDEO_ID&t=123s`のような時刻付きリンクを使える。
2. 読み込み後に、プレーヤーが実際に目的の場面へ移動したことを確認する。URLの時刻だけで到達を判断せず、広告・読み込み中・シーク途中の画像を採用しない。
3. 一時停止した画面と前後の再生を確認する。字幕の発話時刻は探索の起点であり、採用する画面時刻は別に記録する。
4. 利用可能なキャプチャ手段で保存し、保存画像を目視する。ラベルの可読性、操作対象、時刻、説明した状態との一致を確認する。

ブラウザーでURLを開いたこと、ページ本文・字幕を取得したこと、サムネイルを見たことを動画内容の確認と同一視しない。動画閲覧手段がなければ、その制限を記録して下の方法を検討する。

## 必要な場合だけ一時取得する

直接参照では細部が読めない、正確な前後比較やフレーム切り出しが難しい場合は、利用可能な取得手段を使う。ツールやサービスの取得・表示制約に従い、表示制限の回避を目的としたダウンロードは行わない。

- まず保存済み動画を確認する。必要な解像度があれば再取得しない。
- `yt-dlp`、`ffmpeg`、`ffprobe`の有無を確認する。必要な区間または動画だけを作業用の一時ディレクトリへ取得する。高解像度を全動画へ一律要求しない。
- 入力URLは引数として渡す。プレイリストURLから動画全件を意図せず取得しない。取得不能や認証要求を、別動画で確認できたことに置き換えない。
- 取得した動画の長さと解像度を確認する。区間取得した場合は切り出し開始時刻を記録し、ローカル時刻を元動画の時刻へ換算する。
- 音声照合が必要なら音声も保持する。映像のみの取得で発言確認を済ませない。

全編を取得したローカル動画から1フレームを切り出す例。パスと秒数は確認対象に合わせる。

```bash
ffprobe -v error -show_entries format=duration:stream=width,height -of json /tmp/video-research/source.mp4
ffmpeg -hide_banner -loglevel error -i /tmp/video-research/source.mp4 -ss 123.4 -frames:v 1 /tmp/video-research/frame-123.4.png
```

この例の`-ss`はローカル動画の時刻である。シークの精度は保存フレームを見て確認する。説明時刻と画面が合わない場合は周辺を追加で切り出す。動画取得や切り出しの成功だけを内容確認の根拠にしない。

## 採用画像と出典を残す

選定用の一覧画像は探索に使い、最終確認は元解像度の画像で行う。見えない文字や線を生成・補完して証拠画像にしない。拡大表示によって元にない情報が読めたことにしない。

全景は位置関係、細部画像はラベル・設定等の説明に使う。細部は同一フレームからクロップし、元フレームへリンクする。操作を説明する場合は前・途中・後の画像を順に配置し、必要な連続区間を視聴する。静止画だけで動作を断定できなければ未確認を残す。

採用画像を`captures/`へ保存し、`captures/manifest.json`に次の情報を記録する。

| 対象 | 記録する情報 |
| --- | --- |
| 出典 | 出典ID、元動画URL、タイトル、公開日、不明な項目 |
| キャプチャ | 画像ID、相対ファイル名、出典ID、元動画での秒数、時刻付きリンク、観察内容、取得方法、確認日、画像寸法 |
| 細部画像がある場合 | 元画像ID、クロップ画像のファイル名、元画像上の座標と幅・高さ |
| 区間取得した場合 | 元動画上の区間開始時刻とローカル動画上のフレーム時刻 |

ブラウザーの時刻精度が秒単位なら、その精度を記録し、ミリ秒を捏造しない。YouTube以外で時刻リンクを作れない場合は、元URLに時刻表記を添える。期限付きの配信URLや認証情報を出典として保存しない。

本文では画像の直下に、確認できる内容、動画名、時刻付きリンクを添える。画像なしの字幕由来の論点も、発話の時刻または範囲へ戻れるようにする。

## 最後の確認

- 本文の画像・出典ID・時刻とmanifestが一致し、リンク先のファイルが存在する。
- 全景と細部が同じフレームに対応し、必要な文字や図が読める。
- 動画の未視聴区間、字幕の未取得、解像度不足、編集による飛躍などが明記されている。
- 納品物に必要なのは資料・字幕・出典情報・採用画像とし、元動画を恒久保存する場合は利用者の指定に従う。一時ファイルを整理するときは今回作成した範囲だけを対象にする。
