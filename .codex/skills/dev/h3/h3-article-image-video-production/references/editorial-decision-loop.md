# 記事内役割と制作判断

## 目的

対象画像をどう動かすかより先に、記事のどの理解不足を時間表現で補うかを決める。映像単体の派手さではなく、掲載位置での編集機能を判断基準にする。

## Gate 1: 動画化の増分価値

次のいずれかが静止画より明確になるとき、動画化に意味がある。

- 時間変化: 開始、途中、結果の関係
- 動作: 使い方、身体の反応、物体の扱い
- 因果: 何が起き、その結果どうなるか
- 比較: 二案や複数状態の差
- 使用感: 重さ、沈み、支え、扱いやすさ
- 感情: 不安から安心、戸惑いから理解
- 注意: 次の文章へつながる意味のある視線誘導

次の状態なら静止画維持を優先する。

- 得られる変化がズーム、揺れ、瞬きなど意味を増やさない動きだけ
- 本文の説明を映像内で繰り返すだけ
- 商品や人物の崩れのリスクが増分価値を上回る
- 実表示では動きも文字も認識できない
- 動画化の理由が「その枠が画像だから」に留まる

静止画維持は失敗や未着手ではなく、記事編集上の正式な判断として記録する。

## Gate 2: 記事内のコミュニケーション機能

一つのカットに中心機能を一つ置く。必要なら補助機能を一つ加えるが、LP全体が担う導入、根拠、CTAを重複させない。

| 表現クラス | 主な機能 | 映像の中心 | 避けること |
|---|---|---|---|
| 観察・生活情景 | 共感、安心、生活への接続 | 自然な小さな行動や表情 | 広告然とした過演出 |
| 実演・使用証明 | 使い方、扱いやすさ | 手、身体、商品の接触と結果 | 接点を隠す装飾 |
| 状態変化 | Before/After、経過 | 開始と終了の読める差 | 変化前後の混在 |
| 比較・分類 | 違い、正誤、選択 | 対応関係と判別性 | 根拠のない単純化 |
| 構造・機能説明 | 層、支持、厚み、仕組み | 商品形状と注目箇所 | 商品を別物にする模式化 |
| 感覚の可視化 | 痛み、重さ、圧迫など | 身体・物体と追従する補助表現 | 記事にない医学的断定 |
| 文章転換 | 否定、逆接、気づき | 前状態の退出と次の主張 | 古い画面や文字の残留 |
| 文字主体 | 短文の記憶、リズム | 正確な文言と読解時間 | 長文の詰め込み |
| hybrid | 実写だけの曖昧さを補う | 実写を主、図形・文字を従 | 装飾が主役になること |

複数の機能が競合する場合は、周辺本文で代替できないものをカットの中心にする。残りは本文または別カットへ戻す。

## 映像が担う情報とページが担う情報

次を分ける。

- `video_owns`: 動作、比較、位置、変化など、時間表現でしか十分に伝わらない情報
- `page_owns`: 長い説明、注意書き、根拠、CTA、レスポンシブに保持すべき本文

動画内の文字は、本文を丸ごと焼き込むためではない。映像の理解に不可欠な短文、比較ラベル、転換語、対象と一体で追従すべき注釈に絞る。

## 時間設計

秒数の前にビートを列挙する。

1. 認識: 誰・何・どの状態かを把握する
2. 主動作: 一つの中心行為を見せる
3. 変化・比較: 必要な場合だけ差を見せる
4. 読解: 正確な文言を読める状態で保持する
5. 結果: 何が分かったかを落ち着かせる
6. 接続: 必要な場合だけループや次の本文へつなぐ

すべてを必須にしない。単一動作なら短くできる。複数場面、比較、長めの日本語、物理動作を含むなら、それを認識できる尺を確保する。5秒は単一動作カットの暫定候補にすぎない。

生成サービスが離散的な尺しか持たない場合は、必要なビートを失わない最短の対応尺を選ぶ。依頼条件から尺や解像度を変える有料実行は、実行前に確認する。

## 別案を作る判断

同じ仮説をほぼ同じ画面で反復しない。別案は次のいずれかを変えて、異なる編集仮説を検証する。

- 構図: 正面、俯瞰、二分割、フレーム内フレーム
- 主動作: 人物動作、商品動作、画面転換
- 時間構造: 連続動作、対比、完全な切替、マッチカット
- 伝達方式: 観察、比較、図解、文字主体
- 素材戦略: 既存動画利用、開始終了フレーム、新規状態画像

各案に「何を改善または検証する案か」を付ける。単なるズーム量、速度、文字の有無だけが違う案は、ユーザーがその局所比較を求めた場合を除き別案として数えない。
