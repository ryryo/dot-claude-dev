# H3生成単位とリール編集

このリファレンスは`edited`の全単位と、`hybrid`内の`Independent`単位の通常編集を担当する。AV latentを共有するcontinuation groupの生成・結合には`h3-latent-continuation.md`を併用し、独立クリップと同じ接続規則で扱わない。

`Independent`単位のstitch roleは`N/A`とし、`Stitch Ready`や`Final Clip`を付けない。これらはAV latent continuationの保存・trim・結合役割であり、通常のNLE編集上の「最終採用クリップ」とは別概念である。

## 生成単位を設計する

H3の1生成は2〜15秒に収める。完成尺が15秒を超える場合、ストーリーの役割で分割する。

- 15秒以下: 原則1単位
- 16〜30秒: 通常2〜3単位
- 31〜45秒: 通常4〜5単位

単純な等分ではなく、フック、説明、証拠、オファー、CTAの境界で切る。各単位は原則3ショット以内とし、参照素材を詰め込みすぎない。

## AロールとBロールを配置する

次のいずれかを1単位にする。

- Aロール → 対応するBロール
- Aロール → Bロール → Aロール
- 意味の連続するBロール2〜3本
- CTA用の話者または商品エンドカード

話者の主張と証拠映像が遠く離れないようにする。複数単位にまたがる場合、直前の台詞または編集字幕で関係を明示する。

## 接続方法を選ぶ

UGC広告はhard cutを既定とする。次の接続を優先する。

- 話者の視線またはジェスチャー → 指した商品や場所
- 台詞の名詞 → 対応する対象のclose-up
- 手の動き → 次の工程の手元
- 商品の形 → 同じ形の別利用場面
- 音のimpact → オファーまたはCTA

正確な連続動作が必要なときだけ、前単位の終了画像を次単位の開始キーフレームにする。別カットへ切るだけなら、連続フレーム参照を追加しない。

## 参照を再利用する

- 同じ人物と商品は全単位で同じ参照素材と保持属性を使う。
- 各Ref2VAプロンプト内のラベル番号は、その単位へ渡す実際の入力順に合わせる。
- 全体マップの番号を、素材を省いた単位へ無条件に流用しない。
- 使用しない素材は入力しない。
- 店舗の雰囲気だけを参照する画像から、人物や商品まで転写しない。

## 文字を編集レイヤーへ渡す

`Edit Overlay Sheet` は次を持つ。

| 項目 | 内容 |
| --- | --- |
| Exact text | 原文どおりの文字列 |
| Time range | 完成リール全体での表示区間 |
| Function | hook、caption、offer、disclaimer、CTA |
| Placement | upper-center、center、lower-safeなど |
| Treatment | size、contrast、entry、hold、exit |
| Layer | H3 baked-in または post-edit |

短いフック以外はpost-editを既定にする。UIを模した偽の購入ボタン、商品タグ、QRコードを生成しない。

## 音を連続させる

単発生成ではH3内で会話、SFX、BGMを完結できる。複数生成では次を既定にする。

- H3クリップ: 必要な同期SFX、短い会話、自然な環境音
- 編集レイヤー: 全編共通BGM、長いナレーション、音量オートメーション
- カット点: 台詞の途中を避け、必要ならroom toneまたは短いwhooshでつなぐ
- 同じ話者: 同じ声質、速度、感情、距離を記述する。音声参照がある場合は同じ参照を使う

独立生成したBGM同士を直接つながない。各単位で音楽を生成する必要がある場合は、同じテンポ、楽器、調性感、密度を指定し、カット点を明示する。

`hybrid`で連続Aロールの発話中へIndependent Bロールを挟む場合は、映像だけを差し替え、元の話者音声とroom toneをJ-cut／L-cutとして継続できる。構成表とAssemblyに、映像採用区間と継続する音声区間を別々に書き、Bロール側で重複する台詞やナレーションを生成しない。

## 終了を安定させる

最後の区間では新しい主張や素材を追加しない。商品、店舗、人物のうち1つをvisual ownerにし、CTAと必要なブランド情報を編集レイヤーで読める状態に保つ。最終静止開始後はカメラ、文字、人物、商品を動かし続けない。
