# モーショングラフィックス共通文法

## 1. 制約を先に固定する

プロンプト本文より先に、次を内部で一覧化する。

| 項目 | 固定内容 |
| --- | --- |
| Duration / ratio | 利用者指定。任せる場合だけ10秒・16:9 |
| Visual owner | 各ビートで視線を所有する1要素 |
| Exact text allowlist | 表示可能な文字列を引用符付きで列挙 |
| Identity locks | 主役、商品、衣装、色、線、質感、ラベル |
| Reference roles | 各素材から使う属性と無視する属性 |
| Persistent layers | 全編で位置、寸法、z-orderを保持するUI、ロゴ、CTA、装飾。不要ならなし |
| Interaction trigger | tap、press、swipe、impactなど状態変化の起点。不要ならなし |
| Camera policy | locked、または許可した1種類の動き |
| Voice policy | 既定は発話なし。明示時だけ台詞／ナレーション |
| Audio policy | SFXとインストゥルメンタル、または指定された無音 |

未確認のブランド主張や表示文言を補完しない。創作コピーを作る場合は、完成後にallowlistへ固定する。

## 2. 1ビート1主動作

各ビートを次の順序で組み立てる。

1. `enter`: 主役が入る、現れる、組み上がる。
2. `commit`: 主動作が方向と目的を明確にする。
3. `settle`: オーバーシュートや反動を収束させる。
4. `hold`: 文字、商品、構図を読める状態で保つ。
5. `exit/transform`: 次のビートへ視覚的な運動量を渡す。

同時に動かす補助要素は主役より遅らせ、同じ強さで競合させない。単なる「dynamic」「smooth」「professional」ではなく、方向、距離、回転、変形、順序、着地状態を書く。

## 3. 標準語彙を意味アンカーとして圧縮する

After Effects／モーショングラフィックスの標準語彙は、学習済みの視覚・時間構造を短く呼び出す意味アンカーとしてプロンプトに残す。用語を一般語へ言い換えて消さず、用語だけでは一意に決まらない情報だけを補う。

- `owner`: 何が変形するか。
- `origin / axis`: どこから、どの軸で始まるか。
- `direction`: どちらへ進むか。
- `sequence`: 同時、stagger、cascadeなど、どの順序で進むか。
- `next state`: 背後または変形後に何が現れるか。
- `completed state`: 終了時刻に何が確定しているか。

`card flip that flips like a card`のような同義反復は削る。`card flip around the vertical center axis, revealing the blush-pink next state`のように、軸と次状態を加える説明は残す。語彙の選択、変換、監査が必要な場合は、標準アンカーと補足項目を[AIモーショングラフィックス語彙・演出設計](motion-graphics-vocabulary.md)から選ぶ。

全編共通のUI、カメラ、文字規則、人物条件は冒頭で一度だけ固定する。文字数超過時は、品質形容詞、用語の同義反復、共通条件のShotごとの再掲、副次的小道具の順に削る。H3の必須フィールド、参照関係、正確な表示文字、時刻、主動作、因果、次状態、完成状態は残す。

## 4. 可読性を時間として確保する

- 短いキーワードや短句は、完成後およそ0.35–0.5秒を目安に保持する。
- タイトル、CTA、クレジット、長めの行は、およそ0.9–1.3秒を目安に保持する。
- 文字量、画面占有率、コントラストに応じて延長する。目安を満たすために尺を越えてはならない。
- 文字の入場中を可読時間として数えない。変形、ブラー、反転が止まり、正立した完成状態から数える。
- 最終文字と構図は終了前に確定し、最後のフレームまで点滅、揺れ、変形、カメラ移動なしで保持する。
- 最終静止の開始時刻を1つ決める。その時刻以降は、キャラクターの瞬き、呼吸、羽ばたき、微細なfloat、光のshimmerを含め、視覚的な例外を置かない。音楽の減衰または持続だけは許可する。

## 5. 文字を許可リストで守る

- H3の固定フィールド名と順序を崩さない。base modeでは`integrated_multimodal_description`の値の冒頭、Ref2VAでは`detailed_description`の値の冒頭へ、`Use only the exact on-screen text specified below.` と、許可文字列を自然文として入れる。I2VA、FL2VA、L2VAでは、その前に必要なキーフレーム整合文を必ず置く。
- 文字列を英語の二重引用符で囲み、改行や句読点も原文どおりにする。
- fake dates、prices、names、logos、claims、UI labels、QR codesなど、許可されていない情報を禁止する。
- 日本語を英語へ置き換えない。漢字、かな、Latin文字を別の文字種へ置換しない。
- 文字が安定した後にワープ、伸長、モーションブラーをかけない。
- 台詞と同じ文字を字幕として重複表示しない。ただし利用者が字幕を明示した場合を除く。

## 6. カメラと画面内モーションを分離する

文字主体とフラット説明広告ではlocked cameraを既定にし、文字、図形、商品、人物、色面の動きで構成する。商品ヒーローとコラージュでは、主役を強める場合だけ1ビートに1種類のカメラ動作を許可する。

カメラを使うときは、`push in`、`pull out`、`pan`、`truck`、`tilt`、`arc`などの種類、必要な場合は振幅と速度、終了構図を書く。ズーム、パン、ドリー、手ぶれを無自覚に併用しない。

## 7. トランジションに所有者を持たせる

前ビートの主役または意味から次の画面を作る。

- 文字片が次の単語へ再構成される。
- 商品の輪郭や液体がワイプを作る。
- 色面ブロックが画面を覆って次の配色へ渡す。
- シルエット、煙、矢印、カード、円が形状マッチを作る。
- 音のアクセントでhard cutまたはimpact cutする。

理由のない白フラッシュ、粒子、グロー、ランダムなモーフ、同じイージングの反復で転換を埋めない。

トランジション主導の企画では、stable/lookビートを簡潔にし、主役となるtransitionビートへ指示密度を寄せる。transitionビートは`trigger → meaning anchor → ownerの変形経路 → 次状態の露出 → 完了時刻`の因果で書く。すべての案件へ固定のルック数やトランジション尺を適用しない。

## 8. 音をイベントへ結びつける

主要イベントへ短い同期音を割り当てる。

| イベント | 例 |
| --- | --- |
| 文字・カードの着地 | pop、click、paper impact |
| 大見出し・商品確定 | clean impact、stamp hit |
| 分解・再構成・ワイプ | rounded whoosh、swish |
| 液体・氷・素材 | pour、ripple、clink |
| 最終確定 | confirmation impact、final chord |

`non_diegetic_music` にはBPMまたはテンポ感、楽器、密度の変化、主要アクセント時刻、終端の完結方法を書く。SFXとBGMを同じ曖昧な「energetic sound」にまとめない。既定では声、台詞、歌唱を追加しない。

主要トランジションを強調する場合は、直前だけ音楽密度を落とす短いbreathを置き、開始フレームで音を戻してよい。毎回同じ処理を機械的に反復せず、映像上のピークと一致する場合だけ使う。

## 9. 監査と修正

次を重大な失敗として修正する。

- 1ビート内に複数の主役とピークがある。
- 読める前に文字が消える、次の文字と重なる。
- 同一性ロックとショット記述が矛盾する。
- 固定カメラ指定とカメラ移動が混在する。
- SFXや音楽キューの時刻が映像イベントと一致しない。
- 最後の0.45秒以内まで新要素が出続け、安定した終端がない。
- `completely stable` と書いた区間に、`except for a blink` などの視覚的例外が残る。
- `no cuts`または`one continuous shot`と書いた出力に複数のShot見出しがある。
- 連続FL2VAでno cutsと書きながら、複数のShot見出しへ分割する。
- 禁止事項を列挙するだけで、期待する正しい完成状態が書かれていない。
- 意味アンカーの後ろが同義反復だけで、生成を拘束する情報を追加していない。
- persistent layerを各Shotで再記述し、位置、寸法、z-orderが矛盾する。

問題を削除するだけでなく、同じ目的を満たす観測可能な動作、整列、保持状態へ置き換える。
