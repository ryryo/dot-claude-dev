# 店舗・対面サービスリール

## 人と体験を主役にする

- スタッフの顔、髪、衣装、名札、声、役割を生成単位間で固定する。
- 店舗外観、受付、施術・接客空間、主要設備の役割を分ける。
- 話者は悩みを煽る役ではなく、案内、専門性、安心材料を伝える役にする。
- Bロールは手元、工程、空間、道具、接客、完成した提供物で話者の説明を裏付ける。
- 実際の店舗と誤認させる架空の住所、設備、資格、スタッフ数を追加しない。

## 店舗種別に応じた証拠

| 種別 | 有効なBロール |
| --- | --- |
| サロン・整体 | カウンセリング、手元、道具、施術工程、衛生、説明 |
| 飲食 | 調理、盛り付け、湯気、食感、提供、店内の席 |
| 小売 | 商品棚、試着・試用、スタッフ案内、包装、受取 |
| 教室・スクール | 講師、教材、実演、参加風景、制作物 |
| フィットネス | 設備、フォーム案内、サポート、施設動線 |
| 修理・専門サービス | 診断、道具、工程、確認、引き渡し |

同じ施術や設備のclose-upを続けるだけでなく、工程や来店体験が進むように並べる。

## 推奨構成

### 10秒・予約／問い合わせ

1. 0–2秒: スタッフが対象者と提供内容を短く伝える。
2. 2–5秒: 主要な施術、接客、商品、工程を見せる。
3. 5–7秒: スタッフが違いまたは安心材料を伝える。
4. 7–10秒: 追加の証拠と予約・相談CTAを見せる。

### 30秒・体験レポート

1. 来店前の疑問または結果ティザー
2. 入口・受付
3. 説明・カウンセリング
4. 主要な体験を複数Bロールで提示
5. スタッフまたは利用者の短い感想
6. 店舗・サービス中心のCTA

## 事実と表現

- 価格、初回条件、期間、枠数、営業時間、住所、資格を創作しない。
- 健康、美容、身体変化は治療、完治、必ず変わるなどと断定しない。
- Before/Afterは同条件の提供素材と承認済み表現がある場合だけ使い、必要な注意書きを編集レイヤーへ出す。
- 実在顧客の口コミを創作しない。架空の口コミUIや星評価を装飾として追加しない。
- 最終的な広告審査や法令適合は別途確認する。
