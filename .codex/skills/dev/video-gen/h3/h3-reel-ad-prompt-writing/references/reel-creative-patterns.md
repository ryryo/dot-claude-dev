# リール広告の企画パターン

主パターンを1つ選び、必要な場合だけ副パターンを1つ加える。すべての段階を詰め込まない。

| パターン | 適する目的 | 基本構造 |
| --- | --- | --- |
| 問題→解決 | 販売、予約、問い合わせ | 人物が困りごとを提示 → 使用・施術 → 解決方法 → CTA |
| NG・誤解訂正 | 再生、保存、専門性 | 人物が誤解を指摘 → NG例 → 正しい例 → 要点またはCTA |
| How-to | 保存、フォロー、信頼 | 完成形ティザー → 手順 → 注意点 → 要点 |
| 商品実演 | EC販売、機能理解 | 使用結果 → 操作 → ディテール → 利用場面 → 購入CTA |
| 体験レポート | 来店、予約、不安解消 | 来店前の疑問 → 受付・体験 → 感想 → CTA |
| 事例・変化 | 信頼、相談 | 確認済みの変化ティザー → 条件 → 過程 → 結果と注意書き |
| 募集・限定告知 | 予約、リード | 対象者へ呼びかけ → 内容 → 理由・条件 → 期限・枠 → CTA |
| 店舗導線・舞台裏 | 来店、認知 | 入口または完成形 → 移動・準備 → 人・空間 → 来店CTA |

## 選択規則

- 視聴者が商材を知らない場合は、問題→解決または体験レポートを優先する。
- 検討者が機能を疑っている場合は、商品実演または事例・変化を優先する。
- 専門性を伝える場合は、NG・誤解訂正またはHow-toを優先する。
- 店舗へ行く不安が大きい場合は、体験レポートまたは店舗導線を優先する。
- 実在しない希少性を作らない。募集・限定告知は承認済みの条件がある場合だけ使う。

## フックの作り方

短く、対象者と続きを見る理由を持たせる。

- 状況: 「朝、○○に困る人へ」
- 疑問: 「これ、なぜ起きるか知っていますか？」
- 違い: 「似て見えますが、使い方はここが違います」
- 実演予告: 「10秒で使い方を見せます」
- 体験予告: 「初めて行くと何をするのか見てみます」

病気、身体的特徴、年齢、経済状態などを本人について断定する呼びかけにしない。未確認の結果を断定しない。

## CTAの対応

- 販売: 商品を見る、詳細を見る、購入する
- 予約: 空き状況を見る、予約する
- 来店: 場所を見る、店舗を確認する
- 問い合わせ: 相談する、メッセージを送る
- コンテンツ: 保存する、フォローする

複数CTAを並べず、主目的に直接つながる1つを選ぶ。
