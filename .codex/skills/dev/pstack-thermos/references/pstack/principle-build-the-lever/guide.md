# 再実行できる道具を作る

[Codexでの実行規則](../../execution.md)を読んでから使う。

単純な数か所の編集を除き、作業を行う道具か検証する道具を作る。反復回数だけを基準にしない。一度の作業でも再検証に必要なら道具を作る。

最初の一単位を手で処理して手順を理解し、その結果と道具による再実行を比較する。再実行しても安全な形にする。編集にはcodemodやスクリプト、反復ファイルには生成器、分析には再実行可能なクエリ、検証には再実行可能な比較を使う。

全単位を一回で処理できる決定的な道具があれば、同じ作業を人手で行う担当へ分配せず親が実行する。委譲する場合は、全担当が読む手順・検証条件・変更禁止範囲を一つのスキルにし、担当の編集範囲外に置く。

この原則を適用したと述べるなら、差分に実際の道具が必要である。作業がチャットを越えて続くなら道具を保存する。最小のスクリプトで済ませ、枠組みを増やさない。繰り返す指示を強制する `principle-encode-lessons-in-structure` とは用途が異なる。
