# 設計資料の調査

PRD、仕様、RFC、ADR、設計会議、障害分析、runbook、方針資料から理由を探す。利用可能なNotion等の接続を使う。

1. `notion-search` 等で機能名、シンボル、作者、エラー、利用者に見える語、期間を探す。
2. `notion-fetch` 等で候補全文を読み、previewだけで判断しない。
3. 逆参照、子ページ、代案、付録、実装メモを読む。
4. `notion-query-data-sources`、`notion-query-meeting-notes` 等、実際に存在する機能で関連記録を探す。
5. 権限内の作者の資料も調べる。

仕様は実装前の計画であり、PRと照合する。実装とのずれ、定型文、未リンク資料、複数draft、アクセス不能を記録する。各資料の題名、URL、作者、更新日、理由の短い引用と区分、関連リンク、確定・draftの別を返す。
