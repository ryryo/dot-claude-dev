### 実行中プロセスの診断

成果は根拠付きの診断である。実行中の信号を測る。

1. 対象の操作・計測機能でCPUプロファイル、ヒープスナップショット、CDPトレースなどを取得する。
2. 時間の集中する関数、漏れたオブジェクトからGC rootへの参照鎖、入力なしで発火するループまで絞る。大きい成果物はクエリ可能な形にし、許可された分担があれば解析を委ねて主担当には結果と参照先を残す。
3. 診断を信じる前に、実行中プロセスへ計測を入れるなどして仕組みを確かめる。操作や修正は許可された範囲に限る。
4. 割り当て・スケジュールするファイル、シンボル、行へ対応付ける。
5. 分担判断は `throughput checkpoint: n/a, read-only forensics` と記す。

返答には信号、絞り込んだ原因、仕組みの検証、ソース位置、成果物のパスを示す。修正依頼がなければ変更せず、原因が判明したらバグ修正または性能改善へ引き継ぐ。
