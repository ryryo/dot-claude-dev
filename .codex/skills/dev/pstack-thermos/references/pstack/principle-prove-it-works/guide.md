# 実物で成果を確認する

[Codexでの実行規則](../../execution.md)を読んでから使う。

成果物そのものを直接確認する。コンパイル成功、更新時刻、古い画面、担当の自己申告を実際の動作の証明にしない。プロセスの生存は直接確認し、キャッシュや派生表示でなく実際の値を読む。

検証が失敗したら、システムだけでなく観測方法も疑う。可能なら同じ比較を繰り返せる決定的なスクリプトを作り、実行結果をレビューする人が再確認できる成果物として保持する。

証拠の所在を利用者へ示す。大きい移植など、後から追える必要がある作業では `show-me-your-work` に従って記録を保存する。
