# 自分の作業規範をスキルにする

[Codexでの実行規則](../../execution.md)を読んでから使う。

`skill-creator` で限定した `<handle>-mode` を一つ作る。まずプロジェクトの `.agents/skills/` と個人の `~/.agents/skills/` に既存のモードを探し、置換指定がなければ更新する。

`recall` と許可されたTraceDecayの会話検索で最近の証拠を集める。無関係なプロジェクトや非公開のCursor履歴を走査しない。複数の会話で繰り返すか、利用者が直接指定した好みだけを規範へ反映する。一回限りは弱い証拠にする。

証拠で決められない本当の好みだけ少数の質問で確認する。作成・検査・評価を `skill-creator` で行い、個人範囲の指定がなければ `.agents/skills/<handle>-mode/` に置く。`unslop` は例・境界・発動条件を消さず適用する。

客観的に検証できる動作は変更前後の対の評価、主観的な語調はレビュー表示を作って利用者に確認する。明示的な依頼なくPR、push、マージをしない。秘密や一時的な進捗をモードへ保存しない。
