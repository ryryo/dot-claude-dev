# 再利用できる作業の教訓を整理する

[Codexでの実行規則](../../execution.md)を読んでから使う。

現在の会話を主要証拠にする。正確な過去発言がなければ `tracedecay:managing-session-context` を使い、Cursorの履歴ディレクトリを走査しない。

委譲が認められる場合は判断、工具、別案と一般化の三つを独立した読み取り担当へ渡す。各提案は訂正、反復した失敗、一般化できる成功、繰り返す好みに根拠を置く。

提案を `Accepted`・`Rejected`・`Backlog` に分ける。強制できる規則は文章よりコード・lint・メタデータ・スクリプトへ向ける。分析の依頼だけで永続スキルや記憶を書き換えず、分類を提示し明示的に承認された変更を適用する。

承認済みのスキル変更は `skill-creator` で検査し、客観的に試せる動作は限定評価を行う。適用、作成、構造的な残件、却下理由を報告する。秘密や一時的な進捗は保存しない。担当には該当する `*-reviewer.md`、統合には `synthesizer.md` を使う。
