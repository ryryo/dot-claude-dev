## 調べ方

`rg --files` でパスを見つけ、`rg` でシンボルを探し、実装を読む。名前から推測しない。

1. 利用者操作、API、定期処理など、動作を始める入口を特定する。
2. 呼び出しを追い、各関数とデータの変化を読む。
3. 主要な型、インターフェース、サービス、クラスの定義と存在理由を確認する。
4. 他の仕組みとの境界、入力、出力を示す。
5. 意外な動作、履歴由来の部分、初見で誤解しそうな箇所を探す。

追えない箇所は不明と明記する。

## 返す内容

- 流れ。関数、ファイル、処理、次の呼び出し、データを順に示す。
- 読んだ全ファイル。
- 境界の入出力。
- 分かりにくい動作や履歴上の事情。
- 未解決の問い。
