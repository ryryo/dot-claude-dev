# 呼び出し元を移して旧APIを除く

[Codexでの実行規則](../../execution.md)を読んでから使う。

内部APIの変更では、すべての呼び出し元を新しい経路へ移してから、同じ作業単位で旧APIを削除する。利用者の要求や公開互換性が必要な場合を除き、一時的な互換層を残さない。

参照、型、例、テスト、資料を検索し、移植を実際の動作で確認する。旧入口を残すと次の担当がそれを使い、新旧の責務が増える。削除後に残る参照がないか確かめる。

外部の後方互換利用者がなく、同期した破壊的変更を受け入れられる簡素化・リファクタリングに適用する。一時adapterは例外として期限を定める。新しい仕様を検査するテストへ移し、旧実装の内部詳細だけを保護するテストは除く。
