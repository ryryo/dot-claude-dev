# 判定の形式

```md
## 意図
<述べた成果と正確な対象>

## 判定: REVIEW_CLEAN | FINDINGS | INCONCLUSIVE
<一行の判断>

## 確認済み所見
1. **[重大度] 題名** (`file:line`)
   - 失敗場面: <何が壊れるか>
   - 観点: <担当>
   - 証拠: <確かめた内容>
   - 提案: <限定した対処>

## 否定できた懸念
- <確認して成立しなかったリスク>

## レビューの制約
- <足りない証拠、範囲、担当>

## 主担当の判断
- 今直す: <採用所見>
- 後続: <実在する範囲外の懸念>
- 不採用: <誤検知と理由>

## 権限
<このレビューで許可される操作の範囲>
```
