### 見た目の一致

基準画像を仕様として保持し、画像差分で一致を確かめる。

1. 移行前に対象の各状態を撮る比較用の仕組みと基準画像を用意する。基準なしで一致を宣言しない。
2. 合格のために比較手段や基準画像を変えない。差分を消すためだけにコンポーネントを再構成しない。基準が誤って見えたら変更せず、理由を示して確認する。
3. 共有部品を先に移し、その後一つずつ移す。分担が許可されていれば各コンポーネントに担当と専用worktreeを割り当てる。
4. 対象の操作面で各状態を撮って差分を取る。ゼロ以外は不合格として原因を調べ、一致まで再検証する。
5. 依頼範囲ならコンポーネント単位または安全なまとまりで [PR作成](opening-a-pr.md)。

返答には移行した対象、各差分の結果、比較手段の保存場所、残件を示す。
