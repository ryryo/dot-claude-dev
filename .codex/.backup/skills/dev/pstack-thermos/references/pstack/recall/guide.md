# 現在の作業文脈を復元する

[Codexでの実行規則](../../execution.md)を読んでから使う。

話題、作業場所、期間を固定する。「最近」の既定は7日。TraceDecayがある場合は `tracedecay:managing-session-context` と `tracedecay_message_search` で過去の会話、`tracedecay:project-memory` で永続的な事実を調べる。

別の登録プロジェクトが明示されなければ現在のプロジェクトだけを検索する。生の会話を主文脈へ大量に入れず、Cursor履歴や非公開DBを走査しない。見つかったブランチ、コミット、作業、PR、成果は現在の読み取り状態と照合する。履歴は現在の事実ではない。会話外の履歴・Issue・設計・事故は `why` を使う。

要点は最大5項目、各関連作業は根拠付き状態を一行、問題は最大5件、次の安全で有用な動作は一つにまとめる。会話IDや成果物を引用し、公開時は私的情報を除く。
