# 実際の処理経路を説明する

[Codexでの実行規則](../../execution.md)を読んでから使う。

問いが限定的か、複数領域をまたぐかを明示する。TraceDecayで索引化されているプロジェクトでは `tracedecay:using-tracedecay` を使い、概念は文脈検索、記号は検索、呼び出し関係はcallers/calleesへ振り分ける。生の文字列検索から始めない。

実際の操作から効果までを追い、データ構造、状態遷移、境界、失敗経路を含める。意外な主張はコードか実行結果で検証する。概要、主要概念、順序に沿った動作、ファイルと記号の対応、注意点、証拠の不足を返す。変更も依頼されていなければ読み取りだけで進める。

委譲する調査には [探索担当への指示](explorer-prompt.md)、説明には [説明担当への指示](explainer-prompt.md)を使う。
